Delay Calibration Scripts
=========================

analysis.py
-----------
Helper module used by `fitEstimatedSEFD.py`.  From `lwa-project`'s `stress_tests`
repo.

applySelfCalTBX.py
------------------
Given a FITS IDI file generated by correlateTBX.py that contains all valid 
dipoles and both polarizations perform a delay-only self-calibration on the
long baselines using a simple point source model of the sky.

applyDiffuseSelfCalTBX.py
-------------------------
Given a FITS IDI file generated by correlateTBX.py that contains all valid 
dipoles and both polarizations perform a delay-only self-calibration on the
short baselines using the Low Frequency Sky Model as the model of the sky.

checkConsistency.py
-------------------
Given a collection of .sc files generated by applySelfCalTBX.py create a plot
of the delay for each antenna over time and combine the various files into a
master delay file called 'merged.delays'.

classifyData.py
---------------
Given an SSMIF and a collection of TBX files, figure out which are useful for
calibrating the station.  Breaks down the files by being useful for calibration
with:
 * long baselines near the Cyg A transit,
 * short baselines for diffuse calibration, or
 * not useful for calibration/verification only.

convertDelayToStretch.py
------------------------
Given a reference SSMIF and a .sc file generated by applySelfCalTBX.py or the 
'merged.delays' files from checkConsistency.py, convert the delays in ns to stretch 
factors.

applyNewStretchFactors.py
-------------------------
Given an input SSMIF and a collection of stretch factors from 
convertDelayToStretch.py, apply the new stretch factors and create a new SSMIF.

diffSSMIF.py
------------
Given two or more SSMIFs, difference the per antenna delays and create plots
show what changed when and by how much.

estimateSEFD.py
---------------
Given an SSMIF and a collection of TBX files, use phase-and-sum beamforming to make
a basket weave scan across a source to estimate the system equivalent flux density
(SEFD) and pointing error.

fitEstimatedSEFD.py
-------------------
Fit a Gaussian to the results of estimateSEFD.py to determined the SEFD and pointing 
error.

updateBadStands.py
------------------
Script that takes an SSMIF and lists of good, suspect, and bad antennas to generate
a new SSMIF with updated ANT_STAT entries.
